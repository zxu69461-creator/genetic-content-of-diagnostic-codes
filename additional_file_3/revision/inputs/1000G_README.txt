# Integrated phased Biallelic SNP+INDEL call set for the unrelated samples (N=5248)

This directory contains a call set produced by aligning the 1000 Genomes Project sequence data to GRCh38 and calling directly against GRCh38. Multiple callers were used in calling, with the call sets being integrated before final genotyping and phasing.

The set is restricted to biallelic SNVs and INDELs.

This work extends the biallelic SNV data set (http://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000_genomes_project/release/20181203_biallelic_SNV/). This data set uses the same input call sets from the multiple callers but, in this data set, INDELs were included in the remaining processing steps.

The work is described in a Wellcome Open Research data note, which in v1 describes the biallelic SNV only data set. We plan to update the data note to describe the SNV and INDEL data as soon as possible: https://wellcomeopenresearch.org/articles/4-50/

Submission of data to EVA is in progress.
